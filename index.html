Instituts

Entre parenthèses : nombre de sondages retenus avec les autres filtres (période, candidats). Un institut à 0 est grisé : le cocher ou le décocher ne change rien aux résultats.

Mode de simulation

Coché (recommandé) : décocher un candidat ne garde que les sondages où il est réellement absent, et recalcule les moyennes des autres dans ce scénario. Décoché : un candidat retiré disparaît juste du tableau, sans changer les moyennes des autres.

Ajouter un nouveau candidat

Pour un candidat testé dans un sondage mais absent de la liste. Comme pour un sondage, le classement n'est visible par tout le monde qu'après export + dépôt de data.json sur GitHub.

Ajouter un sondage manuellement

À utiliser si un sondage sort avant que Wikipédia (source des mises à jour automatiques) ne l'ait repris. Une fois ajouté ici, il n'est visible que dans votre navigateur : exportez ensuite data.json (carte ci-dessous) et déposez-le sur GitHub pour qu'il soit visible par tous les visiteurs du site. Si Wikipédia reprend ensuite le même sondage, il ne sera pas dupliqué.

Exporter les données à jour

Inclut les sondages ajoutés manuellement. Le fichier data.json peut remplacer celui du dépôt GitHub (par upload direct ou Pull Request).
